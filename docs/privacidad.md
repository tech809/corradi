# Aviso de privacidad — CORRADI-BOT

_Texto propuesto para fijar en el canal de difusión y/o servir con el comando `/privacidad`._

**CORRADI-BOT** es un servicio de Proactive Future que recopila y difunde oportunidades
de movilidad europea para jóvenes (Erasmus+, Cuerpo Europeo de Solidaridad y educación no
formal), dentro del proyecto Erasmus+ KA210 "CORRADI-BOT".

**Qué datos tratamos**
- *Oportunidades*: el texto de las convocatorias y sus datos (fechas, lugar, enlaces de
  inscripción, contacto que la propia convocatoria publica). Es información pública de difusión.
- *Gestores autorizados*: tu identificador de Telegram y nombre de usuario, solo para
  gestionar quién puede aportar oportunidades.
- *Suscriptores del canal*: no recopilamos datos personales; al suscribirte recibes las
  publicaciones, y puedes salir del canal en cualquier momento.

**Para qué y base legal**
- Difundir oportunidades de interés para la juventud (interés legítimo) y gestionar las
  aportaciones de gestores autorizados (su consentimiento al solicitar acceso).

**Con quién se comparte**
- El contenido de las oportunidades se publica en el canal de difusión de Telegram. No
  vendemos ni cedemos datos personales a terceros.
- El texto de cada mensaje se procesa con un modelo de lenguaje (Google Gemini) únicamente
  para estructurar la información; no se usa para perfilar personas.
- El asistente **✨ Preguntar** del mapa envía tu pregunta a **Google Gemini** para
  interpretarla y elegir qué oportunidades abiertas encajan. No se guarda el texto de tu
  pregunta en ningún sitio (ni en claro ni asociado a ti): solo un contador agregado de
  cuántas preguntas se hacen, para el informe de impacto del proyecto. Tampoco se guarda tu
  IP; solo se usa un momento, en memoria, para limitar el nº de preguntas por visitante y
  evitar abusos, y se olvida sola. No escribas datos personales en tu pregunta.

**Conservación**
- Las oportunidades se conservan mientras tengan valor informativo/histórico. Los datos de
  gestores, mientras mantengan el acceso.

**Tus derechos**
- Puedes solicitar acceso, rectificación o supresión de tus datos, o revocar tu acceso como
  gestor, escribiendo a **privacidad@proactivefuture.org**.

> Borrador orientativo; revísalo con la persona responsable de protección de datos del
> consorcio antes de publicarlo oficialmente.
